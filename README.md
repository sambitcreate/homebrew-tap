# sambitcreate Homebrew tap

Homebrew packages for projects published by
[`sambitcreate`](https://github.com/sambitcreate).

## Aiden Agent

Aiden Agent is a macOS AI workspace agent for local and hosted models. The
current cask supports Apple Silicon Macs running macOS Monterey 12 or newer.

Install:

```sh
brew install --cask sambitcreate/tap/aiden-agent
```

Upgrade:

```sh
brew upgrade --cask sambitcreate/tap/aiden-agent
```

Uninstall:

```sh
brew uninstall --cask sambitcreate/tap/aiden-agent
```

Uninstalling the cask removes the application but preserves Aiden's user data,
including `~/.aiden`.
